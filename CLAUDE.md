# Жизнь

Личное приложение: превращает сохранённые видео (Reels, Shorts, YouTube) в базу знаний и дела. Пока только для владельца (не разработчик, Windows 11, iPhone).

Полный исходный промпт: `docs/private/PROMPT.md` (только на ПК владельца, в git не попадает — репозиторий публичный). Макет экранов: `docs/design/Жизнь-экраны.html` (архитектуру и UI строим под него).

## Как работать
- По-русски, на «ты», просто. Маленькие законченные шаги, каждый можно проверить руками.
- Перед этапом краткий план, после — что сделано и как проверить. Код этапа — только после «ок».
- Перед командами, которые что-то ставят или меняют в системе, объяснять что и зачем. Установки, удаления, входы в сервисы — только с разрешения. Изменения на C: — только после анализа и «да».
- **Платить ни за что, кроме подписки Claude.** Только бесплатные тарифы.
- Секреты только в `.env` и секретах Supabase, не в git и не во фронтенде (кроме публичного anon key).
- Если решение из `docs/` мешает или устарело — сначала сказать владельцу, потом менять.
- Коммиты маленькие, названия и сообщения по-русски.

## Суть
iPhone «Поделиться» → Edge Function `add-link` → таблица `sources` (pending). Вручную на ПК запускается обработчик (`python process.py` или `/process`): субтитры YouTube либо yt-dlp + faster-whisper → `claude -p` → карточки `draft`. Веб-приложение (PWA) показывает карточки, владелец подтверждает.

Принципы: одна общая база, сферы — её срезы; у карточки всегда источник и тайм-код; ИИ предлагает, человек подтверждает; карточки строго типизированы (recipe, exercise, rule, idea/tip); модель ИИ меняется через интерфейс `summarize()`; обработчики общаются только с базой.

## Стек
- База и вход: Supabase (Postgres, Auth, Edge Functions), RLS на всех таблицах. Бесплатный проект засыпает после недели без активности — нужен способ держать его живым.
- Веб: React + TypeScript + Vite, статический SPA, supabase-js, PWA. Хостинг: GitHub Pages или Vercel (`*.vercel.app`); проверить, что открывается с iPhone без VPN.
- Обработчик: Python 3.12, yt-dlp, youtube-transcript-api, faster-whisper (large-v3, CUDA на видеокарте ПК), ffmpeg, `claude -p`.
