# Команда iOS «Жизнь» (Поделиться → Жизнь)

Отправляет ссылку из Instagram, YouTube и любого приложения во «Входящие».
Значения адреса, ключа и пароля — в `.env` на ПК (`SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY`, `ADD_LINK_TOKEN`).

## Сборка
1. «Команды» → «+» → название сверху → «Переименовать» → **Жизнь**.
2. Внизу **ⓘ** → включить **«Показывать в меню „Поделиться“»** → «Готово».
3. В появившемся блоке сверху «Получать … из Общего доступа»:
   - «Любые входные данные» → оставить только **URL-адреса** и **Текст**;
   - «Если нет входных данных» → **Получить буфер обмена**.
4. Действие **«Получить содержимое URL»**:
   - URL: `<SUPABASE_URL>/rest/v1/rpc/add_link`
   - раскрыть → Метод: **POST**
   - Заголовки → добавить: ключ `apikey`, значение — publishable key
   - Текст запроса: **JSON** → поля (тип «Текст»):
     - `p_token` → пароль `ADD_LINK_TOKEN`
     - `p_url` → переменная **«Входные данные быстрой команды»**
5. Действие **«Показать уведомление»**: текст `Жизнь: ` + переменная **«Содержимое URL»**.

## Ответы
- `{"ok":true,"duplicate":false,...}` — добавлено.
- `{"ok":true,"duplicate":true,...}` — уже было во «Входящих».
- `"message":"Неверный токен"` — пароль в команде не совпадает с `.env`.
- `"message":"В присланном тексте нет ссылки"` — поделились не ссылкой.
