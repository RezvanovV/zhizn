# Идеи на будущее (НЕ делать в MVP)

- **Telegram-бот как второй вход:** переслал ссылку боту, он кладёт её в Supabase (вебхук на Edge Function). Бот может присылать готовые карточки.
- **Календарь:** Напоминания и Apple Календарь через команды iOS, Google Calendar API. «Запланировать» из карточки, «купить продукты» за день до готовки.
- **Здоровье с Apple Watch** (шаги, пульс, сон, тренировки) через команды iOS, отдельная защищённая таблица, анализ локальной моделью.
- **Предложения по распорядку дня,** делам и блюдам под свободное время.
- **«Что приготовить сейчас»:** фото холодильника или голос + время → рецепт из базы, недостающее в покупки.
- **Меню на неделю** из рецептов и правил питания под цель (набор массы).
- **Чат с ИИ по базе (RAG):** режимы «только моя база» и «база + интернет», со ссылками на источники.
- **Цели и проекты,** связанные со сферами; журнал, центр идей и решений, еженедельный обзор.
- **Контакты с iPhone,** связи между людьми, проектами и материалами.
- **Связка с JARVIS** (голосовой ассистент на ПК): «Жизнь» — его память и планы. API базы делать открытым для помощников.
- Разовый импорт старых сохранёнок из выгрузки данных Instagram.
- Аналоги для вдохновения: Recall, Readwise Reader, Capacities. Связки «видео → дело в календаре» у них нет — это наша фишка.
- Файловый вариант без сервера (на случай блокировки Supabase): команда iOS пишет ссылки в файл в iCloud Drive, ПК читает его оттуда.
