# Решения и причины

- **Supabase, а не Firebase:** нужны таблицы и связи (Postgres). Облако, поэтому ссылки принимаются при выключенном ПК. Бесплатно. Firebase отклонён: документная база и те же риски из РФ.
- **Не VPS:** платить не хотим. Beget к тому же в ноябре 2026 пострадал от кибератаки.
- **Обработка вручную на ПК:** меньше кода, всё под контролем, бесплатно (подписка Claude, локальный Whisper на видеокарте). Автозапуск можно позже.
- **Perplexity не нужна:** видео она не транскрибирует.
- **Нет нативного iOS-приложения:** для него нужен Mac и платный аккаунт разработчика. Хватает PWA и команд iOS.
- **Хостинг — GitHub Pages:** бесплатно, открывается из РФ без VPN. Репозиторий поэтому публичный: секретов в нём нет (publishable key публичный по назначению, данные защищены входом и RLS), личные документы лежат в `docs/private/` вне git.
- **Начинаем узко:** «ссылка → карточка». Остальное надстраиваем.
- **Вход с iPhone — команда iOS (Shortcuts):** PWA на iOS не умеет принимать «Поделиться».
- **Приём ссылок — функция в базе `add_link` (RPC), а не Edge Function:** запускается одним SQL, без деплоя функций и отключения проверки JWT. Пароль хранится только хэшем в `private.settings`. Функция чистит ссылки от меток (`?igsh=`, `?si=`) и не создаёт дублей. Если понадобится логика сложнее (например, сразу узнавать название видео) — можно перейти на Edge Function.
- **Запасной путь, если Supabase недоступен из РФ:** файл в iCloud Drive (см. `IDEAS.md`). Приложение «iCloud для Windows» уже установлено на ПК (20.11.2026) именно ради этого запасного варианта.
- **Макет экранов — часть проекта** (`design/Жизнь-экраны.html`): архитектура данных и UI строятся под него с первого этапа.
