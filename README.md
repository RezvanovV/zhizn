# Жизнь

Личное приложение: сохранённые Reels, Shorts и видео YouTube → карточки знаний (рецепты, упражнения, правила, идеи) → дела на день.

- Цели, стек и правила: [CLAUDE.md](CLAUDE.md)
- Этапы: [docs/ROADMAP.md](docs/ROADMAP.md)
- Архитектура и данные: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
- Макет экранов: [docs/design/Жизнь-экраны.html](docs/design/Жизнь-экраны.html)

## Запуск
Появится по мере этапов:
- веб-приложение (`web/`) — этап 2;
- обработчик (`worker/`) — этап 4.

## Секреты
Скопировать `.env.example` в `.env` и заполнить. `.env` в git не попадает.
